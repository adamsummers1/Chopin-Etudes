Substitution macros

Example: convert a list of chords to a sixteenth note, followed by s8. This is used in chopin op10-2

<<sub_a basic example>>= 
nsss = #(define-music-function (p) (ly:pitch?)
  #{
  $p 16 s8.
  #})

Its important to note that because this is a pitch, you can pass in any length note. However, this doesn't do everything required at that level. Most of the passages contain two notes. These would be represented by chords.

Heres the difference.

;; chord
(make-music
 'SequentialMusic
 'elements
 (list (make-music
        'EventChord
        'elements
        (list (make-music
               'NoteEvent
               'duration
               (ly:make-duration 4)
               'pitch
               (ly:make-pitch 0 0))
              (make-music
               'NoteEvent
               'duration
               (ly:make-duration 4)
               'pitch
               (ly:make-pitch 0 2))
              (make-music
               'NoteEvent
               'duration
               (ly:make-duration 4)
               'pitch
               (ly:make-pitch 0 4))))
       (make-music 'SkipEvent 'duration (ly:make-duration 3 1))))

  • The 'SkipEvent happens after the 'NoteEvent when it's a single note

  • The 'SkipEvent happens after the 'EventChord when its a chord (not the individual notes)

So this means in scheme we could use this logic: Walk thru sequqntial music (which would be a list of pitches):

If we find a 'NoteEvent
    change the duration property to (ly:make-duration 4)
If we find a 'EventChord
    for each 'NoteEvent in the list in 'elements
        change the duration property
then,
add the skip event after the note we found.
<<op10-2.structure-rhythm>>= 
(define (structure-10-2-rhythm p-music-list p-in-chord) 




    (let ((skip-item (list  (make-music 'SkipEvent 'duration (ly:make-duration 3 1))))
        (p-music (if (null? p-music-list) '() (car p-music-list))))
        (cond 
            ((null? p-music) (list))
            ((music-is-of-type? p-music 'sequential-music)

                (let* (
                        (element-result (structure-10-2-rhythm (ly:music-property p-music 'elements) #f))
                        (child-result (structure-10-2-rhythm (cdr p-music-list) #f)))
                    (append element-result child-result)))
            ((music-is-of-type? p-music 'event-chord)

                (let* (
                        (element-result (list (make-music 'EventChord 'elements (structure-10-2-rhythm (ly:music-property p-music 'elements) #t))))
                        (child-result (structure-10-2-rhythm (cdr p-music-list) #f)))
                    (append element-result skip-item child-result)))
            ((music-is-of-type? p-music 'note-event)

                (let* (
                        (current-result (list (make-music 'NoteEvent 'pitch (ly:music-property  p-music 'pitch) 'duration (ly:make-duration 4))))
                        (child-result (structure-10-2-rhythm (cdr p-music-list) p-in-chord)))
                    (if (not p-in-chord)
                        (append current-result skip-item child-result)
                        (append current-result child-result))
                )
            )
           )))
